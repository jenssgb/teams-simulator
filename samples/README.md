# Sample assets

These files let you smoke-test the simulator without bringing your own
audio or avatar.

| File | Description | Provenance |
| --- | --- | --- |
| `demo_audio.wav` | A short synthesised speech-like signal (a few seconds of modulated tone). | Generated by `scripts/generate_samples.py` — public domain. |
| `demo_avatar.png` | A neutral placeholder portrait silhouette. | Generated by `scripts/generate_samples.py` — public domain. |

To regenerate these samples (e.g. after pulling), run:

```powershell
.\.venv\Scripts\python.exe scripts\generate_samples.py
```

Replace them with anything you like for real demos — the simulator
treats them as opaque assets.
